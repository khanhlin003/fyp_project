\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This project designs and implements an AI-assisted Exchange-Traded Fund (ETF) recommendation platform to improve accessibility for retail investors in a complex ETF market. The platform combines a rule-based multi-factor recommendation engine, an AI-powered conversational interface for educational support, news sentiment analysis, and quantitative risk tools including stress scenario analysis and Value at Risk / Conditional Value at Risk (VaR/CVaR).

Built with Next.js, FastAPI, and PostgreSQL, the system supports end-to-end workflows from user authentication and questionnaire-based risk profiling to ETF discovery, personalized recommendation delivery, and wallet-enabled portfolio management. The data layer covers U.S. and Singapore ETF universes with historical market records and related metadata to support explainable analytics.

The results show that combining transparent scoring logic with AI-assisted interaction can provide practical decision support for non-expert investors while maintaining an educational, non-advisory scope. This work contributes a deployable reference architecture for integrating financial analytics, explainable recommendations, and user-oriented AI assistance in retail investment platforms.
